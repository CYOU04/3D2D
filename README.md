## How to Play

### Objective
* Collect the gold coins to win!

### Controls
* Press [ R ] to toggle between 3D and 2D modes.

#### In 3D Mode
* [ W ][ A ][ S ][ D ] -- Move
* [ Mouse ] -- Look around
* [ Space ] -- Jump

#### In 2D Mode
* [ A ][ D ] -- Move Left / Right
* [ Q ][ E ] -- Change Camera Angle
* [ Space ] -- Jump

## プレイ方法 (How to Play)

### 目的 (Objective)
* コインを集めてステージをクリアしよう！

### 操作方法 (Controls)
* [ R ] キーを押すと、3Dモードと2Dモードが切り替わります。

#### 3Dモード時 (In 3D Mode)
* [ W ][ A ][ S ][ D ] -- 移動
* [ マウス ] -- 視点移動
* [ スペース ] -- ジャンプ

#### 2Dモード時 (In 2D Mode)
* [ A ][ D ] -- 左右移動
* [ Q ][ E ] -- カメラアングルの切り替え
* [ スペース ] -- ジャンプ
