## How to Play

### Objective
* Collect the gold coins to win!

### Controls
* Press [ R ] to toggle between 3D and 2D modes.

#### In 3D Mode
* [ W ][ A ][ S ][ D ] -- Move
* [ Mouse ] -- Look around
* [ Space ] -- Jump

#### In 2D Mode
* [ A ][ D ] -- Move Left / Right
* [ Q ][ E ] -- Change Camera Angle
* [ Space ] -- Jump
